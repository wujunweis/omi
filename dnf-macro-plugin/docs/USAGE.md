# DNF宏插件使用指南

## 快速开始

### 1. 安装插件

```bash
# 进入插件目录
cd dnf-macro-plugin

# 安装依赖
npm run install-deps

# 或手动安装
npm install
```

### 2. 启动插件

```bash
# 开发模式（带调试工具）
npm run dev

# 正常模式
npm start
```

### 3. 基本使用流程

1. **录制宏**
   - 点击"开始录制"按钮或按F9键
   - 在DNF游戏中执行你想要自动化的操作
   - 点击"停止录制"按钮或再次按F9键

2. **保存宏**
   - 录制完成后，输入宏的名称
   - 点击"保存宏"按钮

3. **播放宏**
   - 选择要播放的宏（从下拉列表或刚录制的）
   - 设置播放选项（循环次数、速度等）
   - 点击"开始播放"按钮或按F10键

## 详细功能说明

### 录制功能

#### 支持的操作类型
- **鼠标点击**: 左键、右键、中键点击
- **鼠标移动**: 记录鼠标移动轨迹（可选）
- **键盘按键**: 所有键盘按键的按下和释放
- **鼠标滚轮**: 滚轮上下滚动
- **时间间隔**: 精确记录操作间的时间间隔

#### 录制技巧
1. **开始录制前准备**
   - 确保DNF游戏窗口已打开
   - 将角色移动到合适的位置
   - 清理背包，准备好需要的道具

2. **录制过程中**
   - 动作要清晰、准确
   - 避免不必要的鼠标移动
   - 保持稳定的操作节奏

3. **录制完成后**
   - 检查录制的操作数量是否正确
   - 给宏起一个有意义的名称
   - 及时保存避免丢失

### 播放功能

#### 播放选项
- **循环播放**: 勾选后可以重复执行宏
- **循环次数**: 设置具体的循环次数（1-9999）
- **播放速度**: 调整执行速度（0.5x-3.0x）

#### 播放模式
1. **单次播放**: 执行一次完整的宏序列
2. **循环播放**: 按设定次数重复执行
3. **无限循环**: 持续执行直到手动停止

#### 安全提醒
- 播放前确认游戏状态正确
- 随时准备按F11紧急停止
- 不要在重要场景（如团本、PK）中使用

### 快捷键系统

| 快捷键 | 功能 | 说明 |
|--------|------|------|
| F9 | 录制控制 | 开始/停止录制宏 |
| F10 | 播放控制 | 开始/停止播放宏 |
| F11 | 紧急停止 | 立即停止所有操作 |
| Ctrl+Shift+R | 重新录制 | 快速开始新的录制 |
| Ctrl+Shift+P | 快速播放 | 播放最后一个宏 |
| Ctrl+Shift+S | 快速保存 | 保存当前宏 |
| Ctrl+Shift+L | 窗口控制 | 显示/隐藏主窗口 |

### 宏管理

#### 保存宏
1. 录制完成后自动生成宏名称
2. 可以修改为更有意义的名称
3. 宏文件保存在`macros/`目录下

#### 加载宏
1. 从下拉列表选择已保存的宏
2. 点击"加载"按钮
3. 查看宏的详细信息

#### 删除宏
1. 选择要删除的宏
2. 点击"删除"按钮
3. 确认删除操作

## 高级技巧

### 1. 优化录制质量
- **减少鼠标移动**: 只录制必要的点击操作
- **标准化操作**: 保持一致的操作习惯
- **分段录制**: 将复杂操作分解为多个简单宏

### 2. 提高播放准确性
- **调整速度**: 根据网络延迟调整播放速度
- **添加缓冲**: 在关键操作间增加等待时间
- **环境检查**: 确保游戏环境与录制时一致

### 3. 宏的组合使用
- **序列执行**: 手动依次执行多个相关宏
- **条件判断**: 根据游戏状态选择不同宏
- **循环嵌套**: 在大循环中使用小循环

### 4. 性能优化
- **清理无用宏**: 定期删除不需要的宏文件
- **合理命名**: 使用有意义的宏名称便于管理
- **备份重要宏**: 导出重要宏文件进行备份

## 故障排除

### 录制问题
1. **无法开始录制**
   - 检查是否以管理员权限运行
   - 确认没有其他程序占用输入设备
   - 重启插件尝试

2. **录制操作不完整**
   - 检查录制过程中是否有中断
   - 确认所有操作都在录制时间内
   - 查看录制信息中的操作数量

3. **录制文件过大**
   - 避免录制过多的鼠标移动
   - 减少不必要的操作
   - 分段录制复杂操作

### 播放问题
1. **播放不准确**
   - 调整播放速度
   - 检查游戏窗口位置是否改变
   - 确认游戏状态与录制时一致

2. **播放中断**
   - 检查系统资源使用情况
   - 确认没有其他程序干扰
   - 查看错误日志信息

3. **快捷键无效**
   - 检查是否有其他程序占用快捷键
   - 确认插件窗口处于活动状态
   - 重新注册快捷键

### 系统问题
1. **权限不足**
   - 以管理员身份运行插件
   - 检查杀毒软件设置
   - 添加插件到信任列表

2. **依赖缺失**
   - 重新安装依赖包
   - 检查Node.js版本
   - 更新系统驱动程序

3. **兼容性问题**
   - 检查操作系统版本
   - 更新游戏客户端
   - 尝试兼容模式运行

## 安全建议

### 使用原则
1. **合规使用**: 遵守游戏规则和服务条款
2. **适度使用**: 避免过度依赖自动化
3. **安全第一**: 不在重要场景使用

### 风险提醒
1. **账号安全**: 可能被检测为外挂程序
2. **数据丢失**: 操作失误可能造成损失
3. **系统稳定**: 长时间运行可能影响系统

### 防护措施
1. **备份数据**: 定期备份游戏数据和宏文件
2. **测试环境**: 在小号或测试服务器上测试
3. **监控使用**: 密切关注使用效果和风险
