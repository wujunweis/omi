# DNF宏插件

一个专为DNF（地下城与勇士）游戏设计的宏录制和回放插件，支持录制鼠标点击、键盘按键等操作，并可以循环播放。

## 功能特性

### 🎯 核心功能
- **宏录制**: 实时录制鼠标点击、键盘按键、滚轮操作
- **宏回放**: 精确回放录制的操作序列
- **循环播放**: 支持设置循环次数或无限循环
- **播放速度**: 可调节播放速度（0.5x - 3.0x）
- **时间精确**: 保持操作间的时间间隔，确保准确性

### 🎮 游戏优化
- **全局快捷键**: F9录制，F10播放，F11紧急停止
- **后台运行**: 窗口置顶，不影响游戏操作
- **低延迟**: 优化的事件处理，减少输入延迟
- **稳定性**: 错误处理和恢复机制

### 💾 宏管理
- **保存宏**: 将录制的宏保存为文件
- **加载宏**: 快速加载已保存的宏
- **宏信息**: 显示宏的详细信息（操作数、时长等）
- **删除管理**: 方便的宏删除功能

## 安装说明

### 环境要求
- Windows 10/11 (推荐)
- Node.js 16+ 
- Python 2.7 或 3.x (用于编译原生模块)

### 安装步骤

1. **克隆项目**
   ```bash
   git clone <项目地址>
   cd dnf-macro-plugin
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动应用**
   ```bash
   npm start
   ```

```bash
# macOS版本

# Linux版本

```

## 使用指南

### 基本操作

1. **录制宏**
   - 点击"开始录制"按钮或按F9键
   - 在游戏中执行需要录制的操作
   - 点击"停止录制"按钮或再次按F9键

2. **播放宏**
   - 确保已录制或加载了宏
   - 设置播放选项（循环、速度等）
   - 点击"开始播放"按钮或按F10键

3. **保存宏**
   - 录制完成后，输入宏名称
   - 点击"保存宏"按钮

4. **加载宏**
   - 从下拉列表选择已保存的宏
   - 点击"加载"按钮

### 快捷键说明

| 快捷键 | 功能 |
|--------|------|
| F9 | 开始/停止录制 |
| F10 | 开始/停止播放 |
| F11 | 紧急停止所有操作 |

### 高级设置

- **循环播放**: 勾选后可设置循环次数
- **播放速度**: 调整宏的执行速度
- **窗口置顶**: 保持插件窗口在最前面

## 技术架构

### 核心技术
- **Electron**: 跨平台桌面应用框架
- **robotjs**: 系统级鼠标键盘控制
- **ioHook**: 全局输入事件监听
- **Node.js**: 后端逻辑处理

## 注意事项

### 安全提醒
- 本插件仅用于合法的游戏辅助，请遵守游戏规则
- 不建议在竞技模式或PVP中使用
- 使用前请备份重要游戏数据

### 兼容性
- 主要支持Windows系统
- 部分功能在macOS和Linux上可能受限
- 建议在游戏窗口模式下使用

### 性能优化
- 录制时会消耗一定CPU资源
- 建议关闭不必要的后台程序
- 长时间录制可能产生大文件

## 故障排除

### 常见问题

1. **无法录制输入**
   - 检查是否以管理员权限运行
   - 确认杀毒软件未阻止应用

2. **播放不准确**
   - 调整播放速度
   - 检查系统负载情况

3. **快捷键无效**
   - 确认没有其他程序占用快捷键
   - 重启应用尝试

### 日志查看
应用运行时会在控制台输出详细日志，可用于问题诊断。
